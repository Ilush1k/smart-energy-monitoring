# Контракты и поток данных

Браузер обращается к Django через `/api/`. Gateway обслуживает авторизацию, чтение агрегатов и разрешённые операции адаптера. Управление источниками требует staff-доступа. Аналитические запросы к FastAPI выполняются с сервера, а не напрямую из браузера.

Адаптер читает исходные измерения и заменяет агрегаты в одной транзакции на выбранный день. Диапазоны задаются как `[from, to)`; незавершённые дни не должны интерпретироваться как полный период. Перед применением профиля требуется успешная проверка схемы и отображений.

Отсутствующее измерение сохраняет значение NULL: его нельзя заменять измеренным нулём. Для полной мощности нужны общий показатель либо все валидные фазы. Средние используют число валидных значений соответствующего показателя, а энергия зависит от подтверждённого интервала и единиц измерения.

Django использует отдельные подключения для авторизации, метаданных источника и аналитических агрегатов. Базовые таблицы описаны в `database/aggregate_tables.sql`; перед использованием нужно сверить актуальные счётчики с `adapter/schema.py`. SQL не применяется автоматически при запуске.

Уведомления читают готовые суточные агрегаты и учитывают полноту данных. SMTP настраивается отдельно. API источников хранит только разрешённые серверные подключения; ключ шифрования реестра не должен попадать в исходники.
