# Состав публичной версии

Включены React-интерфейс, Django gateway, FastAPI-аналитика, адаптер, тесты, математическая справочная CSV-таблица и описание схемы агрегатов. Исходники отобраны из рабочей версии проекта; рабочая инфраструктура не переносилась.

Не переносятся действующие подключения и токены, TLS-ключи, пользовательская база, рабочие измерения, локальные архивы сборки и инструкции доступа к инфраструктуре. Вместо готового frontend-архива Dockerfile собирает интерфейс из исходников.

Ранний Word-отчёт не соответствует полноте текущей реализации и содержит поля шаблона. Он не добавлен как техническое описание. Текущие README и документация опираются на структуру и контракты кода.

Контекст — учебная командная работа по энергомониторингу. Для резюме необходимо отдельно указывать собственные задачи и вклад; наличие общей кодовой базы не означает индивидуальное авторство каждого модуля.
